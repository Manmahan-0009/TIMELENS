# Antigravity Workspace Instructions — TimeLens

This workspace incorporates four dedicated Antigravity development skills located in `.agents/skills/`:

1. **`context-keeper`**: Always consult `context-keeper` before substantial development. Ensure `.context.md` remains accurate, under 100 lines, and synchronized after every major change.
2. **`responsive-mobile-first`**: Apply `responsive-mobile-first` when creating or modifying user interfaces. Prioritize fluid layouts, touch targets (≥48px), and responsive breakpoints (375px, 768px, 1440px).
3. **`ui-ux-pro-max`**: Apply `ui-ux-pro-max` when designing UI components, themes, and layouts. Follow the Digital Heritage theme palette (`#0B1220`, `#172235`, `#E8B86D`, `#F8FAFC`, `#A7B4C7`).
4. **`security-first`**: Apply `security-first` when handling files, user inputs, API requests, credentials, or output rendering. Strictly protect secrets, sanitize uploads in memory (≤10MB, PIL verification), and prevent injection.
