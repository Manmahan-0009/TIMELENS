# UI/UX Pro Max Skill

Create a premium experience for TimeLens.

## Design Philosophy

TimeLens should feel like a modern digital heritage archive.

Prioritize usability, visual hierarchy, accessibility,
and clarity over decorative effects.

## Typography

Prefer:
- Inter
- Outfit
- Plus Jakarta Sans

Use appropriate fallbacks.

Avoid making remote font loading mandatory.

Use comfortable line heights and clear heading hierarchy.

## Layout

- Clean hero section
- Clear upload controls
- Responsive image comparison area
- Distinct analysis results
- Consistent card spacing
- Professional footer

## Visual Effects

Use subtle:
- Gradients
- Rounded corners
- Soft shadows
- Translucent surfaces
- Gentle hover states

Avoid excessive glassmorphism.

Do not reduce text readability.

## Interactions

Provide:
- Clear button states
- Loading indicators
- Informative success messages
- Helpful errors
- Visible keyboard focus states

Respect reduced-motion preferences.

## Icons

Prefer accessible vector icons where practical.

Avoid excessive emojis in the application interface.

## Accessibility

- Maintain sufficient color contrast.
- Do not communicate status through color alone.
- Use meaningful labels.
- Support keyboard navigation.
- Keep text readable on mobile.
- Avoid unnecessary motion.

## Performance

Do not add heavy frontend packages only for decoration.

Use Streamlit-native components wherever possible.

## Final Rule

A reliable functional interface is more important
than advanced animations.
