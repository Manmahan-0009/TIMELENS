# TimeLens Project Context

### Project Objective
TimeLens discovers and analyzes how historical places have evolved over time by comparing historical and contemporary photographs using Gemma 4 multimodal AI.

### Current Technology Stack
- Language: Python 3.13.5
- Web Interface: Streamlit 1.66.1
- Multimodal AI SDK: Google GenAI SDK (`google-genai==2.33.0`)
- Model: Google Gemma 4 26B (`gemma-4-26b-a4b-it`) via Google Gemini API
- PDF Generation: ReportLab 5.1.0 & PyPDF 6.21.2
- Image Processing: Pillow 13.0.0
- Environment Management: python-dotenv 1.2.4
- License: Apache-2.0

### Core Architecture
- **Presentation Layer** (`app.py`): Streamlit dashboard with Digital Heritage UI, dual uploaders, interactive before/after split-screen slider, preservation scorecard, visual change explorer, and dual PDF/JSON exports.
- **PDF Generation Service** (`services/pdf_service.py`): In-memory publication-ready A4 PDF generator using ReportLab with embedded photo plates, scorecard KPIs, and dynamic page numbering.
- **Image Processing Service** (`services/image_service.py`): In-memory validation, EXIF normalization, aspect-ratio downscaling (≤1280px), and SHA-256 content hashing.
- **Report Schema & Validation Service** (`services/report_service.py`): Schema enforcement, enum validation, export serialization (`timelens_heritage_report.json`), and cached demo loading.
- **AI Inference Service** (`services/gemma_service.py`): Google GenAI SDK client, dual-image multimodal prompt orchestration with JSON mode & prompt fallback, retry recovery, and sanitized error handling.
